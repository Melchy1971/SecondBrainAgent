# Release 30.61 — Single Source of Truth fuer die Version

## Problem
Die Version war widerspruechlich ueber das Projekt verteilt:
- `pyproject.toml`: `30.60.0`
- `README.md`: `v30.46`
- `docs/09_MASTERPLAN_STATUS.json`: `30.46`
Es gab kein zentrales `version.py` und keinen `__version__`. Launcher/GUI/CLI meldeten keine Version.

## Loesung
`pyproject.toml` ist ab jetzt die **fuehrende Versionsquelle**. Alles andere leitet sich ab.

### Neu
- `secondbrain/version.py` — kanonische Quelle. Liest `pyproject.toml` (`[project].version`);
  Fallback auf installierte Paket-Metadaten nur, wenn kein pyproject vorhanden ist (Wheel-Fall).
  API: `get_version()`, `version_tuple()`, `get_build_number()`, `version_info()`, `__version__`, `__build__`.
  Buildnummer deterministisch: `major*10000 + minor*100 + patch` (30.61.0 -> 306100).
- `secondbrain/__init__.py` — exportiert `__version__`/`__build__` aus der zentralen Quelle.
- `secondbrain/gui/version.py`, `secondbrain/cli/version.py` — GUI/CLI uebernehmen dieselbe Version
  (`APP_VERSION`, `CLI_VERSION`). (gui/cli sind Namespace-Packages; additive Module, keine `__init__`-Aenderung.)
- `secondbrain/version_sync.py` — `sync_version(project_root)` schreibt die abgeleiteten Anker
  (`docs/09_MASTERPLAN_STATUS.json`, README-Titelzeile) idempotent neu; historische Referenzen bleiben.
- Launcher: `python launcher.py version` (JSON mit version/build/…), `python launcher.py version-sync`,
  `launcher.__version__`.

### Geaendert (nur Versionsanker, kein Funktionsverhalten)
- `pyproject.toml`: `30.60.0` -> `30.61.0`.
- `README.md`: Titel `# SecondBrain-Agent v30.61.0` + Abschnitt „Version (Single Source of Truth)".
- `docs/09_MASTERPLAN_STATUS.json`: `version`/`current_version`=`v30.61.0`, `build`=306100,
  `version_source`=`pyproject.toml`.

### Verhalten
Kein bestehendes Funktionsverhalten veraendert (Commands, Sync, GUI unveraendert). Additiv sind
Versions-Reporting-Pfade. Einzige Pfad-Aenderung: `launcher.py --version` gibt jetzt die Version aus,
statt (wie bisher ohne Positional) die GUI zu starten.

Fertig — README, Masterplan, Launcher/GUI/CLI ziehen automatisch nach.
