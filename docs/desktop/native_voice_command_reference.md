# Native Voice Command Reference

- Wake Words: `Jarvis`, `Hey Jarvis`, `SecondBrain`
- Navigation: `Öffne Dashboard|Aufgaben|Projekte|Dokumente|Suche|Memory|Kalender|Mail|Jobs|Freigaben|Einstellungen|Diagnose`
- Dokumente: `Importiere Datei` (Bestätigung und Workspace erforderlich)
- Kalender: `Erstelle Termin` (Approval und Workspace erforderlich)
- Mail: `Sende Mail`, `Sende Antwort` (Approval und Workspace erforderlich)
- Freie Sprache: wird als Assistant-Anfrage behandelt.

`Ja`, `bestätigen` oder `ausführen` wirken nur bei einem aktiven, nicht abgelaufenen Dialog.
