# v31.45 Voice State Integration

- Verbindet Mikrofonaufnahme und lokale Transkription mit der zentralen Voice-State-Machine.
- Zeigt den aktuellen Voice-Zustand separat in der nativen Desktop-Kopfleiste an.
- Bewahrt Mute- und TTS-Sperren auch bei Statusmeldungen aus Audio-Threads.
- Macht STT-Fehler als `ERROR` sichtbar, ohne die GUI zu blockieren.
