# v31.53 Runtime Diagnostics

- Zeigt Voice, STT, Mikrofon, Wake Word, Hotkey, Tray, Jobs und Approvals gemeinsam an.
- Meldet fehlendes Mikrofon oder STT-Modell als Degraded Mode statt Startblocker.
- Verwendet eine explizite Allowlist ohne Secrets, Payloads, lokale Pfade oder Gerätenamen.
- Die Diagnose ist read-only und löst keine Reparaturen oder Downloads aus.
