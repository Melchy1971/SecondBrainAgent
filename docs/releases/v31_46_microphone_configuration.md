# v31.46 Microphone Configuration

- Konfigurierbare Mikrofon-Geräteauswahl über `SECONDBRAIN_MICROPHONE_DEVICE_INDEX`.
- Begrenzte Werte für Noise Calibration, Aufnahme-Timeout und maximale Sprachdauer.
- Read-only Geräteinventar für Desktop-Diagnosen.
- Fehlende Audio-Backends und ungültige Konfigurationen blockieren den Desktopstart nicht.
