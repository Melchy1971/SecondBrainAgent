# v31.49 Dialog Prompts

- Zeigt verständliche Rückfragen für fehlende Slots im nativen Desktop an.
- Bestätigungen bleiben nicht blockierend und können per Sprache oder Text beantwortet werden.
- Approval-Hinweise enthalten keine Empfänger, Inhalte oder sonstigen Payload-Werte.
- Optionale Prompt-TTS ist über `SECONDBRAIN_DIALOG_TTS_ENABLED` explizit aktivierbar.
