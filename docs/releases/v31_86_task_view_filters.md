# v31.86 Native Task View Filters

The native Tasks view now supports workspace-local projections for all, open,
completed, and archived tasks. Global lifecycle counts remain visible while the
item list and visibility limit apply only to the selected filter.

Dedicated read-only actions make every filter directly available to typed and
spoken commands. Selecting a filter opens the native Tasks view without
modifying the task store, and invalid internal filter values fail explicitly.
