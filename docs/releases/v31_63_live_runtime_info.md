# v31.63 Live Runtime Info

The native Jarvis top bar now reflects the current release-gate blocker count,
embedding health and PostgreSQL selection instead of keeping startup
placeholders. The System Info panel exposes an allowlisted runtime log level.

The clock card also derives its German month and full year from the same local
clock used for time and date. Unknown configuration values are normalized and
never forwarded verbatim to the interface.
