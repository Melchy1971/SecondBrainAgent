# v31.58 Live Vault Status

The native Jarvis dashboard now replaces its static Vault markdown and Inbox
examples with counts from the existing read-only desktop live-data provider.
Only normalized counts and availability labels reach the native status panel.

The provider now supports both repository-local `SecondBrain` /
`SecondBrain-Inbox` directories and the established sibling-directory layout.
Existing sibling resolution remains the fallback for compatibility.
