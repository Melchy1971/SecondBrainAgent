# v31.48 Spoken Slot Continuation

- Freie Folgeäußerungen füllen den jeweils nächsten fehlenden Dialog-Slot.
- `Ja` kann nicht versehentlich als Slotwert oder ungebundene Bestätigung verwendet werden.
- Aktive Dialoge lassen sich explizit abbrechen.
- Jede Folgeäußerung bleibt an den ursprünglichen Workspace gebunden.
