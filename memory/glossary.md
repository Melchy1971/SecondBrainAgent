# Glossary

Decoder ring für Kürzel, Systeme, Projektbegriffe. Quelle: SecondBrain-Vault (04_Tasks, 01_Projekte).

## Systeme / Tools
| Term | Bedeutung |
|------|-----------|
| myWiki | Internes Telekom-Wiki zur Wissenssicherung und Dokumentation |
| SAP | ERP-Systemlandschaft der Telekom; hohe Komplexität, Offshoring/Dienstleisterwechsel als Herausforderung |
| Jira | Ticket-/Board-System für Anforderungen und Prozessdesign |
| Obsidian | Markdown-Notiz-App; verarbeitet Backlinks — Basis des SecondBrain-Vaults |
| Vault | Der `SecondBrain/`-Ordner (Obsidian) |

## SecondBrain-System-Begriffe
| Term | Bedeutung |
|------|-----------|
| Watcher | Automatisierung, die den Vault befüllt (zu testen in v0.3) |
| Journal | Journal-Funktion im Vault |
| Daily Digest | Tägliche System-Zusammenfassung |
| Inbox | `SecondBrain-Inbox/` — Eingang für zu importierende Notizen (z.B. `Claude/`) |
